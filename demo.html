Kyber Client-Server Demo

The demo calls /app/… (app backend) and /api_server/… (Kyber server). On your machine both run in the same project; in production they would usually be separate. Use the browser’s Network tab and Console to inspect requests and logs.

1. Get the server public key

The client fetches and stores the server’s public key.

Endpoint:

2. Create a shared secret on the client

The client gets the server public key and derives and stores a shared secret and encapsulates it.

3. Send the ciphertext to the server

The client sends the ciphertext to the server to decapsulate it with its private key and store the shared secret.

Endpoint:

4. Encrypt a message on the client

The client encrypts a message with the saved shared secret.

5. Decrypt the message on the server

The client sends the payload to the server to decrypt it using the shared secret.
